important shortcuts 
ctrl + g to group objects
ctrl + shift + g to ungroup objects
ctrl + D to duplicate
ctrl + shift + c to transform
h to flip horizontally
b to flip vertically
1 to 100 percent zoom
2 to 50 percent zoom
4 to move drawing to center
ctrl+shift+f to open fill and stroke dialog
ctril+shift+a to align dialog
